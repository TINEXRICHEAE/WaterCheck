## Try it yourself (dev stack running)

Run the commands in a terminal **in `watercheck\infra`** (where `docker-compose.yml` is), each pasted as **one line**. They run the admin CLI inside a one-off `migrate` container that can reach the database.

```powershell
cd C:\Users\ocenr\Desktop\Research\app\watercheck\infra
```

1. Create a stakeholder:

   ```
   docker compose run --rm migrate python -m app.cli create-stakeholder --username you@example.org --full-name "Your Name" --area UG-ABIM
   ```

2. Open `http://localhost/console/` and sign in with the temporary password. Choose a new password. The dashboard shows "Your areas: Abim" and there is no Admin entry. Reload the page: you stay signed in.
3. Create an activation code:

   ```
   docker compose run --rm migrate python -m app.cli create-activation-code --area ABIM-ENT
   ```

   Open `http://localhost/collect/`, accept the notice, enter the code, and choose a PIN.
4. Revoke that installation. Copy the installation ID from Collect's Settings ("Installation ID: …"), then run:

   ```
   docker compose run --rm migrate python -m app.cli revoke-installation <installation-id>
   ```

   Reload the Collect preview: the "switched off" screen appears.
