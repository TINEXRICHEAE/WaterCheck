# P3 demo — Offline collector workflows

- Date: 2026-10-10
- Evidence so far: automated widget tests run against an in-memory database with **no network at all**. The browser preview is at `http://localhost/collect/`.
- The device run in airplane mode, the low-end phone check and the field walkthrough are **deferred to P12** (decision D-B: gate items that need people or devices).
