  - Console › **Reports**: the PDF report (save or print) and the readings CSV, for the area and period chosen on the dashboard;
  - a source's page › **Community notice**: A4 or A5, print or save.

## Gate checks

| Gate item | Evidence | Result |
|-----------|----------|--------|
| **The PDF from demo data is checked against a checklist: totals match database queries (automated test on the numbers)** | Data test `report numbers match database queries` on the P9 fixture (50 sources, 500 tests, 2,000 readings). It checks against independent SQL: sources, sources tested, tests in the period, abnormal tests, abnormal tests with a documented action, and collectors active. A second test checks that a correction replaces what it corrects, in the report and the CSV.<br>**Checklist (rendered and inspected):** title, area, period, generated date; limit sets used (provisional flag, custom changes); impact indicators; sources with their latest values against safe ranges and a status word; alerts with what was done; limitations statement; page numbers. | ✅ |
| **The CSV re-imports into a spreadsheet with correct types; the row count matches the filter** | Data test: one row per reading of the filtered tests (count equals SQL), every row parses (UTC dates, numeric values, integer version); one area gives fewer rows. pandas loads the fixture's export as **2,000 rows**, typed `datetime64[UTC]`, `float64` and `int64`. | ✅ |
| **A notice printed on a real printer and judged readable at 1 m** | A4 and A5 notices rendered and inspected: banner type 28 pt with a symbol and words, steps 20 pt with icons, values table 15 pt. | ⏳ The real printer and the 1 m reading need a person and a printer: deferred to P12 (D-B). |
