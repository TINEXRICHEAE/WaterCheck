## Other P8 work

- **Same alert ID on phone and server** (UUID v5 of result + trigger): no duplicates whichever syncs first (errata G7). Shared vector Python ↔ Dart.
- **Server baseline:** the server classification now uses the source's safe history, so baseline-jump alerts are raised server-side too.
- **Routing** by area and responsibility (`alert_routing_rule`). Stakeholders without responsibilities get everything in their area.
- **Job queue:** retries 8 times with backoff, then marks the notification failed (tested).
- **Collect:** "Send by SMS" appears on the alert screen after 6 hours unsynced, once the gateway number is set. It composes the §8.5 message with its 6-character code (shared vector) and opens the SMS app. Phones learn their short code at activation or the next status check.
- **Console:**
  - the Alerts section lists open (or all) alerts;
  - the alert screen shows readings, history (who and when), and the actions: acknowledge, action, close, false alarm, request lab confirmation, add a note;
  - the bell shows unread notifications and opens the alert.
- **Not yet active:** push registration on devices (needs the Firebase project) and outbound SMS through Africa's Talking (needs the key). Errata G14 is settled: on Windows, in-app plus email.
